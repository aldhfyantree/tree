# شجرة الضفيان — Firebase

مشروع ثابت جاهز لـ Firebase Hosting وCloud Firestore.

## النشر من Google Cloud Shell — النسخة الدائرية

```bash
unzip -o aldhfyan-tree-firebase-v4.zip -d aldhfyan-tree-v4 && cd aldhfyan-tree-v4 && firebase deploy --project aldhfyantree-f3273
```

تعرض النسخة الجديدة ضفي في الوسط والفروع الأربعة حوله. يمكن التكبير والتحريك، والبحث يحدد الشخص ويضيء مسار نسبه. بيانات Firestore الحالية لا تتغير أثناء النشر.
